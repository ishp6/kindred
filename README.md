# Mine or Borrowed

A guided check-in for empaths: name a feeling, trace where it came from, find out if it's yours or borrowed, then breathe and set it down.

Plain HTML, CSS and JS. No build step. History is stored in the browser (localStorage) only.

## Run locally
Open `index.html`, or run `npx serve .`

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. In Vercel: Add New > Project > import the repo.
3. Framework preset: Other. Leave build command and output directory empty. Deploy.

Or from the terminal: `npx vercel` inside this folder.
